# 자동차 경주 (Racing Car)

## 📌 개요
입력받은 자동차들이 주어진 횟수 동안 전진 또는 정지하며,  
게임 종료 후 가장 멀리 간 자동차를 우승자로 결정하는 프로그램입니다.  
TDD 기반으로 단계적 구현을 목표로 합니다.

---

## ✅ 기능 요구 사항

### 1. 입력
- 사용자로부터 **자동차 이름 목록**을 입력받는다.
    - 이름은 쉼표(`,`)로 구분한다.
    - 각 이름은 1자 이상 5자 이하이어야 한다.
    - 형식에 맞지 않는 경우 `IllegalArgumentException`을 발생시킨다.
- 사용자로부터 **시도할 이동 횟수**를 입력받는다.
    - 숫자여야 한다.
    - 1 이상의 정수여야 한다.
    - 유효하지 않은 경우 `IllegalArgumentException`을 발생시킨다.

### 2. 전진 조건
- 각 자동차는 **0~9 사이의 무작위 수**를 생성한다.
- **4 이상**이면 전진하고, 그렇지 않으면 정지한다.
- 전진 조건은 **전략 패턴**을 적용하여 테스트 가능하도록 구현한다.

### 3. 경주 진행
- **한 라운드**에서 모든 자동차가 전진 여부를 검사한다.
- 게임은 입력받은 **횟수만큼 반복**되며,
- 매 라운드 종료 후 **현재 상태를 출력**한다.

### 4. 우승자 판정
- 가장 멀리 간 자동차가 우승자이다.
- 우승자는 **한 명 이상**일 수 있다.
- 우승자가 여러 명이면 쉼표(`,`)로 구분하여 출력한다.

## 🧱 설계 개요

### 계층 구조

| 레이어 | 역할 |
|--------|------|
| **domain** | 핵심 로직(전진, 우승 판단) / Random, Console에 의존 ❌ |
| **view** | 입력 및 출력 처리 (Console 기반) |
| **application** | 전체 흐름 제어, 도메인 호출 |
| **main** | 프로그램 실행 시작점 |

### 주요 도메인 모델

- `Car` : 이름과 현재 위치 보유, 전략에 따라 이동
- `Cars` : 자동차 컬렉션, 라운드 진행/우승자 판단
- `Name` : 유효한 이름인지 검증하는 값 객체
- `Position` : 음수가 될 수 없는 위치 값 객체
- `Attempts` : 시도 횟수 입력 검증
- `MoveStrategy` : 이동 여부를 판단하는 전략 인터페이스
- `RandomMoveStrategy` : Randoms 라이브러리 활용한 구현체
- `RacingGame` : 라운드 진행 및 스냅샷 생성 역할
